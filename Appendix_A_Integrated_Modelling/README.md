# Appendix A — Integrated fire severity modelling

This directory contains Python research scripts supporting the integrated fire-severity modelling analyses presented in Appendix A of the PhD thesis. The analyses examine meteorological, topographic and fuel/vegetation predictors, environmental-domain comparisons, base ML models, context-aware ensembles, model interpretation and spatial sensitivity.

## Repository contents

| Component | Scripts | Research focus |
|---|---|---|
| Data preparation and validation | `01`–`03` | Dataset preparation, base-model evaluation and attention-based ensemble modelling |
| Environmental and contextual analyses | `04`–`07`, `10`–`11`, `16`, `19B` | Context-specific comparisons, environmental-domain combinations, uncertainty and sensitivity analyses |
| Interpretation | `08`–`09`, `22`–`23` | SHAP, GAM and ensemble interpretation |
| Spatial assessment | `13`–`15` | Spatial autocorrelation, severity heterogeneity and spatial-block validation |
| Figures and tables | `12`, `17`–`18` | Generation of supporting appendix figures and tables |
| Shared settings | `appendix_config.py` | Paths, response and predictor fields, environmental domains and common settings |

The numbered filenames are retained to preserve references and dependencies between scripts. Some analyses require outputs generated by preceding scripts.

## Research workflow

1. Prepare the modelling dataset and establish the training and testing partitions.
2. Fit and evaluate RF, XGBoost, SVM and MLP base models, followed by context-aware ensemble analyses.
3. Compare meteorological (M), topographic (T), and fuel/vegetation (FV) predictor domains, including their combined configurations.
4. Examine model interpretation, uncertainty, spatial heterogeneity and sensitivity to spatial validation choices.
5. Generate the supporting figures and tables for Appendix A.

## Model configurations

The `appendix_config.py` defines 31 predictors: 10 meteorological, 12 topographic and 9 fuel/vegetation variables, alongside seven environmental-domain combinations. The predictor list is retained as configured for the integrated modelling analyses. Individual scripts also record experiment-specific model settings. Refer to the thesis for the methods, results and interpretation.


## Model configurations
The analyses were conducted using Python, with supporting statistical analyses where applicable. Required packages are listed in requirements.txt.
Input and output directories, predictor definitions and common analysis settings are managed through appendix_config.py. Users should configure local paths and ensure the required datasets and preceding model outputs are available before running the scripts.

## Research use

These scripts document the analytical methods and selected model configurations supporting Appendix A. The thesis provides the methodological context, final results and scientific interpretation. Execution with another dataset or computing environment may require local configuration.
